零依赖 TypeScriptAgent 运行时评测闭环MCP消融实验面试准备包技术文章
一句话概述：独立设计与实现了一个带可复现评测闭环的 DeepSeek Agent 运行时——不只是"调 API 拼 prompt"，而是把 agent 变成可度量、可复盘、可回归的系统，并用真实跑分量化了每个机制的贡献。

一、目的与背景

  • 目标：产出一个"含金量高、替代性不强、可写进简历"的系统级项目，用于校招/实习投递。
  • 核心主张：模型决定上限，harness 决定下限。价值不在模型，而在围绕模型的工程与度量。
  • 约束：面向在校生，需在无团队、个人可维护、成本可控（DeepSeek API，全量评测约 0.1–0.2¥/轮）前提下体现真实工程深度。

二、范围与关键技术决策（含取舍）

决策选择理由 / 放弃的方案
运行形态TypeScript CLI + 本地网页回放放弃单文件 HTML：真实评测需文件系统/进程/网络能力，CLI 更合适且无 CORS 问题
依赖零第三方包、无构建用 Node 24 原生运行 .ts；降低审阅/复现门槛，规避依赖腐化
模型后端OpenAI 兼容 provider 抽象，默认 DeepSeek可换任意兼容端点；但当前仅对 deepseek-chat 做过真实评测
沙箱进程级 + Node --permission 运行时隔离本机无 Docker；容器化列为后续路线，诚实标注网络/Python 不受该模型约束
判分独立判分器（不复用被测模型）避免"模型给自己打分"导致指标虚高

三、工作过程（分阶段）

  1. 核心运行时：provider 层（指数退避重试）、7 个工具、执行沙箱、主循环。
  2. 上下文与续跑：按"回合"分组的 LLM 压缩 + 规则兜底；trajectory.jsonl 事件溯源 + 原子快照断点续跑。
  3. 评测闭环：4 类判分器、任务集、并发 runner、成本核算、CLI。
  4. 回放面板与自检：单文件 HTML 轨迹回放；离线 selftest；README。
  5. MCP 客户端：手写 stdio JSON-RPC 握手与工具桥接（命名空间化），含离线测试服务器。
  6. 扩充与度量：任务扩到 22（难度标注 + 按任务上下文预算）；新增 bench（pass@R/方差/flaky）。
  7. 真实跑分与修复：连真实 API 跑分，定位并修复 4 个 mock 测不到的跨层缺陷。
  8. 含金量强化：OS 强制沙箱、终止/交付物兜底、GitHub Actions CI。
  9. 研究级严谨：消融实验、成本/时限护栏、失败归因分类、provider/MCP 韧性自检。
  10. 发布：建仓、MIT、按个人身份提交并推送、CI 上线。

诚实声明（评审后修订）：本报告早期版本给出的"套件可靠性 98.5%±2.1% → 100%±0%""护栏 +4.5%""压缩 −4% token" 等数字已撤回。原因见 §5.2：首轮消融为单轮（n=1）、压缩对照组实为空跑（baseline 自身压缩事件=0）、 且 g01 的旧判分规则过松（只要求 ≤240 字符且含关键词）。可信数字须"每配置 R≥3、逐任务配对、报 pass@R/中位数"重测后再给。

5.2 消融实验（deepseek-chat，22 任务真实跑分）

配置均值%中位%最低%均 prompt tokenflaky
baseline（全开）98.510095.57773g01
关闭上下文压缩97.095.595.57761g01
关闭收尾/交付物兜底97.095.595.57422g01

结论（R=3 配对重测，已推翻首轮）：按评审建议把消融从 n=1 改为每配置 R=3 配对重跑（4 配置 × 22 任务 × 3 轮 = 264 次任务运行，每次含多轮真实 API 调用）后， 四个配置全落在噪声带内（均值差 1.5%、中位几乎一致），g01 在 baseline 里也 flaky，"关压缩"的 prompt token 与 baseline 几乎相同（7773→7761）。即：在 R=3 下没有任何机制呈现可统计分辨的通过率效应，早期"护栏 +4.5%""压缩 −4%"的单轮结论被本次重测证伪。 唯一稳定可复现的信号是开放式任务 g01 的终止 flakiness，且现有护栏并不能可靠消除它。这份"自我证伪"数据保留在 results/ablation.json。

七、已知局限与诚实声明

  • 沙箱残留：Node 权限模型不拦截网络；run_py 无对等的零依赖隔离（工具层路径约束 + 超时）。生产需容器后端。
  • 判分文件保护（已加固）：验收脚本标 protected——write_file 拒改 + 判分前 sha256 校验（HEAD 13e541b），模型用 run_js 偷改 test 文件会被判 grader_tampered；自检已锁死该路径。
  • 压缩触发：保留组已改为随 token 预算缩放（不再硬编码 keep=4），真实跑分中 x07/x10 现能触发压缩（compactions=1）；但多数任务仍 ≤8 回合完成，压缩只在长链/紧预算下生效。
  • 度量数字待重测：可靠性/消融的具体百分比当前不主张，需 R≥3 配对重测。
  • 单模型：仅对 deepseek-chat 评测过。
  • 已完成：默认分支已切换为 main，冗余的 master 已删除。
